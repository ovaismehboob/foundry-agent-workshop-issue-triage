# Contoso Telecom - eSIM, SIM, Voicemail and Device Guide

Document ID: KB-DEV-020
Classification: Synthetic training content for the Microsoft Foundry agent lab.

## eSIM activation fails or shows "No SIM"
- Each eSIM QR code can be used only once. If the customer scanned the code on another phone, or deleted the
  eSIM profile, the code shows "already used".
- Fix: Issue a new eSIM QR code. The customer can request it in the Contoso Telecom app (Account > SIM > Replace eSIM)
  after identity verification, or in any store with a valid ID.
- Priority guidance: If the customer has no working SIM at all, treat as P2 (complete loss of service).

## Voicemail not working after changing phone
- Ask the customer to reset the voicemail PIN by dialling 1210 (fictional short code).
- Check call forwarding settings on the new phone. Some phones turn off "forward when unanswered" by default.
- Priority guidance: P3.

## Device will not charge (device bought from Contoso Telecom)
- Devices bought from Contoso Telecom have a 12-month manufacturer warranty.
- First steps: try a different cable and charger, and clean the charging port gently.
- If the device is still not charging, the customer can bring it to any Contoso Telecom store with the receipt for a warranty assessment.
- Priority guidance: P3.
